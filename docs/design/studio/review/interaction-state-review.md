# Module interaction-state review — SP02

This supplement is the reviewed interaction acceptance specification, not a replacement for the immutable reference SVG or the domain contracts. The source
inventory at 3128c0e shows 23/23 modules use the same generic state skeleton.
The following state scenarios are module-specific design acceptance requirements.
All transitions use the selected tenant/workspace/revision; stale responses
must be discarded. Loading is distinct from empty, unavailable, invalid,
denied and failed; retain last valid state only with an explicit stale label.
No automatic mutation follows a retry. Where an action persists state,
success requires authoritative acknowledgement.

| Module | Navigation and initial loading | Invalid input / unavailable data | Keyboard path and recovery acceptance |
|---|---|---|---|
| UI01 | Navigate shell, load saved layout and selected tab; restore only after topology and revision validation. | Unknown layout version, invalid split ratio, missing monitor or inaccessible revision. | Tab to workspace and splitter; keyboard resize; restore defaults on invalid layout; verify visible window, selected revision unchanged, focus returns to selected tab. |
| UI02 | Open recent workspace or connection, load manifest; enter backup preview before restore. | Non-workspace directory, corrupt digest, unsupported schema, expired connection or inaccessible path. | Keyboard select path and restore target, cancel preview without mutation; failed restore retains previous workspace and exposes retry. |
| UI03 | Load health, runs and connector panels independently; drill into exact revision. | Unavailable counters, empty runs, stale health, unauthorized integration. | Keyboard refresh only failed panel; inspect run link; distinguish empty history from failed run fetch and verify stale labels. |
| UI04 | Open frozen revision into draft canvas; load palette and inspector. | Dangling variable, invalid resource unit, unsupported type or stale validation response. | Add/edit by keyboard instead of drag, navigate error to field; cancel edit preserves original revision; save creates new revision only after validation. |
| UI05 | Load revision incidence; filter, search and trace selection; compare pinned second revision. | Missing/deleted node, unavailable provenance, unknown revision, incompatible comparison. | Select hyperedge and all incident IDs by keys; clear filter and restore selection; keep deleted node explicit in diff; verify unfiltered graph unchanged. |
| UI06 | Open source document, load language services; validate edit version. | Parse/type error, unsupported formatter feature, stale diagnostic. | Navigate source span, correct and revalidate; discard delayed result from previous edit; failed format retains original text and cursor. |
| UI07 | Load constraint and typed expression; edit bounds, units and penalty. | Incompatible dimensions, invalid bound, unsupported soft constraint, proof unavailable. | Focus invalid operand and correct; compare equivalent units and preserve draft on failed save; proof unavailable not a conflict proof. |
| UI08 | Load ordered objective vector; edit goal and contribution preview. | Duplicate priority, invalid weight, incompatible currency, unsupported Pareto request. | Change direction/weight/order with keyboard; reject invalid save and preserve vector; unavailable preview has no fabricated contribution. |
| UI09 | Load representation and transform mapping; inspect exact source span. | Unsupported lowering, absent transform proof, stale revision. | Switch representations and follow mapped row; retain only valid selection; absent mapping shows unavailable and allows return to source. |
| UI10 | Load adapter capabilities and budget schema; check eligibility before submit. | Unsupported option, nonpositive budget, unavailable adapter manifest. | Navigate option diagnostics, correct and resubmit eligibility; cancel has no run side effect; rejected config never creates run. |
| UI11 | Load run snapshot then subscribe from sequence; inspect observed events. | Missing bound/CPU/memory, duplicate or out-of-order event, sequence gap, failed subscription. | Select event, cancel with acknowledgement, refresh on gap; retain verified incumbent; unknown progress remains indeterminate and null never becomes zero. |
| UI12 | Load run capability and component trace; compare full solve. | Search events not exposed, missing invalidation proof, incompatible baseline. | Navigate component tree and evidence link; show unavailable trace, not synthetic events; retry fetch without re-running solver implicitly. |
| UI13 | Choose baseline and alternative, load each frozen result; compare. | Missing baseline, incompatible units/objectives, unavailable risk estimate or failed alternative. | Keyboard choose revisions, inspect changed input and evidence; disable incomparable delta; preserve baseline when alternative fails. |
| UI14 | Load experiment, seed and distribution schema; validate then start/replay. | Invalid distribution/budget/seed, no samples, truncated or cancelled experiment. | Keyboard correct config, replay seed and inspect sample/quantile table; display actual completed sample count and termination; never extend distribution with synthetic observations. |
| UI15 | Load machine calendar and assignment; compare alternative interval. | Overlapping downtime, missing machine, unassigned operation, unavailable feasibility result. | Keyboard inspect schedule table and operation/Gantt equivalent; show original model checks; failed load distinct from verified absence of feasible plan. |
| UI16 | Load resource and horizon; compute/display authorized allocation evidence. | Zero denominator, incompatible unit, missing capacity or incomplete assignment. | Select resource and contributor by keyboard; change horizon and reconcile totals; undefined utilization is not idle or zero. |
| UI17 | Load evidence by exact run/revision; verify digest, checks and certificate independently. | Digest mismatch, denied tenant, missing certificate, unverifiable proof. | Navigate constraint row to source; export and reverify; never upgrade math status from absent certificate; failed verification explicitly labeled. |
| UI18 | Load baseline and eligible explanation capabilities; request forced alternative. | Incompatible budget/revision, unsupported discrete sensitivity, unknown proof. | Select alternative and inspect binding row; cancel or retry without altering baseline; only evidence-backed claims shown as proven. |
| UI19 | Load suite and paired observations, then environment manifest. | Missing failed trial record, incompatible unit/environment, unmatched instance or unsupported metric. | Keyboard choose paired samples and failed trial; export exact manifest; keep failures in counts and suppress incomparable statistics. |
| UI20 | Load connector schema; stage mapping, preview rows, validate before commit. | Invalid transform/unit, stale schema, unauthorized credential, row rejection. | Edit mapping by keys and inspect source-row diagnostics; cancel discards stage; atomic rejection leaves prior revision intact, credentials redacted. |
| UI21 | Load authorized tenant context and role matrix, then versioned SDK/extension details. | Expired token, denied permission, stale policy version, cross-tenant identity. | Navigate as read-only user and attempt privileged action; server rejection is observable, no optimistic success; refetch policy and restore safe focus. |
| UI22 | Open palette, load registered commands for current capability/context. | Unknown or denied command, invalid arguments, stale workspace or restricted shell action. | Search and invoke same command via shortcut or palette; Escape restores opener; no unrestricted shell, privileged actions require explicit authorization. |
| UI23 | Load effective config into editable draft; validate, persist, restart and reread. | Invalid setting, stale config revision, unavailable diagnostic, redacted secret. | Keyboard switch language/theme, correct invalid field; failed apply keeps previous effective config; export redacted report, partial diagnostics explicit. |
