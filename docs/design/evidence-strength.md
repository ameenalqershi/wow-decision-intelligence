# S05 — Bound assessment and exact enumeration

Scope #30 / TC-S05-A. S01 result shape validation and S04 original primal verification are prerequisites. No compiler, lowering, solver or native backend is called. Host supplies an authoritative EvidenceBinding (tenant/model/revision/run, original UDIR SHA-256, exact selected facts SHA-256, measurement catalog SHA-256). The observation is bound by the trusted orchestration to the admitted attempt; never construct its binding from an untrusted adapter response. Copy and hash the actual catalog/fact bytes before use. Catalog is a strict internal JSON snapshot of M04 unit definitions, currencies and calendars (not a new public wire schema). Facts must belong to original UDIR input digests. S10/S12 own durable storage and authenticated selection of these snapshots. An identical reference string or result shape alone cannot establish origin, freshness or authenticity.

BoundAssessment distinguishes reported mathematical status, termination, independently verified primal status, bound evidence level and complete exact proof. S01 checks direction and order. Verify the original witness again using S04. For minimization the attested bound is a lower bound; for maximization an upper bound; inconsistent order rejects. A zero gap or an adapter's Optimal/Infeasible/Unbounded status never becomes independently proved merely because the report is structurally valid. Unknown bound has unknown gap. An adapter-provided IndependentCertificate label is rejected until a checker for that certificate format exists. The solver's original status/evidence and numerical tolerance metadata are retained separately; reported evidence is untrusted. Gap is exact |incumbent-bound| and relative gap divides by max(1, |incumbent|) in the declared objective units. A gap involving an attested bound is conditional on the attestation, not a certified gap. No rounding or fabricated bound.

Exact enumeration proof profile: deterministic UDIR original model, one objective with unit weight, hard constraints, Boolean or bounded integer decisions, frozen facts, no scenario recourse. Enumerate full Cartesian domain in stable ordinal variable order; call S04 on every assignment. A point is eliminated only when the original hard predicate is evaluated false; undefined arithmetic, unsupported operations, missing facts, incomplete reports or failed recomputation abort the proof. Recheck each feasible point using independently computed exact objective value; compare fractions in objective direction. The minimum/maximum of the complete feasible set is an exact global bound. Empty complete feasible set proves infeasibility; partial enumeration never does. Retain checked/feasible counts and a deterministic exact witness. An independently discovered witness is not represented as the solver's incumbent. A contradictory attestation is rejected or a nonoptimal solver witness downgraded; solver termination is not changed. Cap 4096 assignments and 1,000,000 estimated original-model expression/symbol/constraint visits per pass, cancellation checked between points and inside S04. No claim of scalable optimization; larger or continuous domains cannot use this proof. Multiobjective stage bounds, soft-penalty composition, staged uncertainty, LP dual certificates and cross-revision bound transfer require explicit qualified semantics/checkers and are not accepted by this profile. No use of solver evidence for decision authorization.

Tests: locked restore and Release tests in tests/Verification.Bounds. Eight cases cover both exact objective directions, 13-point domain / 9 feasible, two-variable 25-point negative objective compared with independent integer oracle, infeasibility by full enumeration, budget/cancellation, forged certificate, foreign scope, stale facts/catalog/run, bound direction/order, zero-gap attestation and unknown gaps. No performance claims. S10 should retain scope, input and catalog bytes, original solver identity/report, proof algorithm version and recomputable proof; S12 must not expose the internal snapshot DTO as a new public API. This is the scoped enumeration proof path required by TC-S05-A, not LP dual or general multiobjective qualification.
