## Admitted domain and proof

The profile is closed: UDIR 1.0 without extensions, deterministic hard constraints, one unit-weight zero-tolerance objective, dimensionless finite integer or Boolean decisions, fixed numeric parameters/resources only. All original expressions (including unreachable nodes) must be total within the conservative numeric profile. Arithmetic permits integer literal/reference, add/subtract/negate and multiplication by an expression with no variable reads. Comparisons are equality or order of scalar expressions; nested predicates, nonlinear multiplication, division, unknown features, non-singleton facts, continuous/temporal/unit/currency/scenario/soft/multiobjective semantics are rejected explicitly. This is a structural certificate for the admitted original mathematical model, not for external unmodeled policies: the caller must supply a complete admitted UDIR with all global/resource rows materialized. EDG presence or a resource name alone is not proof of mathematical independence.

Induction in topological order establishes each numeric expression as c + sum(a_i x_i). Addition, subtraction, negation and multiplication by a fixed constant preserve this form. Bounds on absolute coefficient/activity keep every original intermediate integer within 10^12. Boolean leaf variables are encoded by 0/1 and reconstructed as true/false; comparison evaluates an affine difference against zero. Each hard row's variable-read set is computed from the original expression DAG, retaining even terms algebraically cancelled. Union all variables read by each row, including shared capacity rows. Empty scopes are checked separately. Consequently each row involves at most one connected component, and after constant predicates hold, F equals the Cartesian product of the local feasible sets. A shared fixed number does not couple two otherwise independent rows, but a shared resource capacity over multiple decision variables does.

The affine objective is c + sum_j f_j(x_j) with f_j the sum of its coefficients in component j. If all local sets are nonempty, sum of their minima plus c lower-bounds every feasible minimization point and the concatenated minimizers attain it; reverse inequalities for maximization. One fully exhausted empty component or false constant predicate proves infeasibility in this admitted profile. For every admitted local domain, mixed-radix enumeration visits each point once. No partial enumeration may publish a solution or infeasibility claim. Preflight caps total local assignments at 4096 and estimated solving work at 2,000,000 operations; cancellation propagates. Returned proof scope contains original model SHA-256, component variable/row IDs, constant row IDs, count and complete reconstructed candidate. No serialized certificate is trusted as input. A full S04 check must succeed before exposing VerifiedOptimum; mismatch returns VerificationFailed with no witness or objective.

## Complexity and limits

Let V be variable count, N DAG nodes, E DAG edges, R rows. With conservative immutable read sets and affine maps, worst-case storage O(NV+E+R+V) and time O((N+E+R)V log(V+1)) before enumeration (includes ordered maps/set operations and conservative union processing). Source admission caps V=256 and N,R=4096. Solve work is O(sum_j P_j (v_j + r_j + t_j)), where P_j is the local domain product, v_j variables, r_j rows and t_j coefficient incidences, plus one original witness check. Full enumeration would examine product_j P_j points; the dense case has one component and no combinatorial saving. Conservative source incidences may merge otherwise separable models, intentionally reducing opportunities rather than certifying false independence. No wall-time, memory or novelty claim. A cache, cross-revision bounds, general rational affine scope and native integration remain separate work.
