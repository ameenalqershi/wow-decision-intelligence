# M07 · Exact semantic normalization

This workstream owns semantic admission and exact normalization, not native lowering, presolve, independent verification or solver execution. The normalization layer consumes canonical UDIR and the shared M04 measurement catalog. It does not mutate the original revision, publish transformed content into the registry, or use the semantic projection as evidence identity.

## Exact normalization foundation

`ExactNormalizer.Normalize(UdirDocument, MeasurementSemantics, CancellationToken)` validates the existing bounded UDIR wire and measurements before rewriting. It traverses the expression DAG iteratively in stable ordinal topological order. Arithmetic uses reduced BigInteger rationals; numerators and denominators are bounded by the existing 256-digit profile. No floating-point, lossy narrowing, approximate transformation or implicit exchange rate is used. Constant operations fold exactly. Addition, multiplication and equality canonicalize operand order (except instant shifts, whose typed operand order remains explicit). Identical typed nodes share a canonical node identity only after comparing the entire canonical node key. Every original expression has a rewrite entry with its original ID and span. All hard and soft constraints, objectives and domains are preserved; duplicate-row and unused-variable elimination belong to M12.

For division, conservative exact interval propagation must establish that the denominator excludes zero. An integer/instant result must have a provable integral value. Unsupported or unprovable cases fail closed; these are conservative admission limits rather than proofs that the model is infeasible. DML-DIV-001 identifies division that cannot be proved safe, DML-NUM-001 denotes exact profile overflow, DML-NUM-002 denotes unproved integrality, and DML-NUM-003 denotes canonical node-key collision. Original structural/measurement diagnostics retain their contract code. Cancellation throws OperationCanceledException.

`NormalizedModel` retains Original, canonical nodes, per-expression Origins, rows/goals and canonical mathematical projection bytes. The projection includes the time basis, symbol roles/domains/types, reachable typed expression graph, row identity and hard/soft penalty, objective direction/priority/weight/tolerance, scenarios and required capabilities. It excludes source positions, revision identity and unreachable intermediate expression nodes, but the original and all lineage remain available. This projection is only a conservative exact comparison profile; it does not establish general algebraic equivalence, tenant authorization, equivalence of external inputs or reusable proof identity. Compare canonical bytes, not just a digest. Never use it as a registry revision or cross-tenant cache key. Unit-scale aliases and operational metadata require further explicit semantic handling.

## Bound DML admission

`DmlCompiler.Compile(bound, options, cancellationToken)` consumes the actual M06 BoundDocument, the explicit trusted tenant/model/revision/time basis, measurement registry and frozen host input digests. It generates a structurally validated UDIR document and runs the same exact normalizer. Source bytes and SHA-256 are retained verbatim; generated flat JSON fact snapshot uses exact string values, with its explicit FactsDigest in the result and UDIR InputDigests. The original bound syntax and references remain available for source lineage. The caller must supply the actual frozen bytes for the host catalog/timezone and other external input digests at registry publication; a supplied digest is not itself proof of catalog identity.

- Value declarations are exact constant expressions (including acyclic dependencies on immutable facts). Numeric non-variable facts have fixed bounds unless explicitly overridden in a scenario. Boolean facts use the frozen fact snapshot; Boolean domains remain implicit. Reject a decision-dependent initializer/bound or one depending on a scenario-varying fact, rather than precomputing a stale derived value.
- Decision intervals, hard and soft rows, exact positive penalty, unique lexicographic priorities, objective directions and source spans are preserved. Every original UDIR expression, including initializer and domain expressions, has a normalization lineage entry. Parentheses and hard-policy assertions retain their source spans in the bound AST; a hard policy in this mathematical profile asserts an already-hard constraint and never alters its hardness.
- The host may specify explicit rational aliases for known units (e.g. USD as Money, hour as Duration, USD/hour as Rate). Int declarations remain Integer. Same-type operations require identical units; literal-only expressions can use an exact common rational representation. Product/quotient unit spelling is constructed by cancellation of identical atoms; M04 independently checks actual dimension and exact scale of every product. No implicit scale or currency conversion. Distinct currencies require explicit versioned FX; pre-normalize imported facts via M04. RelatedSpan identifies the other operand or declaration on type conflicts.
- The DML 0.1 scenario syntax expresses independent one-stage alternatives. One root named root records baseline overrides; branches inherit those baseline facts unless explicitly overridden. Numeric domains cover exactly the extrema of declared baseline/alternative values; the actual admitted branch facts, not arbitrary intermediate values, are preserved by root/branch overrides. No probability is invented. The staged.uncertainty capability is required. Imported UDIR sibling probabilities must be either all absent or all supplied and sum exactly to one. The independent verifier currently rejects scenario execution as unsupported, so normalization is not scenario-solver qualification.
- Time basis and elapsed units are validated by M04. Windows require explicit offsets, positive duration and matching calendar, but UDIR v1 cannot encode operational windows or precedence/trigger/source scheduling semantics; return DML-CAP-001 rather than silently dropping them. The published Batch example with operational declarations binds successfully but cannot be admitted as an executable mathematical revision in this profile. A caller must use an explicit approved EDG/runtime profile to admit those semantics. Reciprocal-only units not representable by the current unit grammar also fail closed. No native backend or connector is invoked.

The mathematical projection intentionally excludes external facts and source bytes. Comparing normalized mathematical bytes is not sufficient for full model equivalence: compare the exact frozen non-variable facts, admitted catalog/time basis, capability and scenario context as well. In particular Boolean facts are not determined by their implicit domain. Never reuse verification/evidence identity based solely on the semantic digest.

## Acceptance evidence

The workforce test calls the real S04 OriginalVerifier on every enumerated witness with the frozen fact bytes and original UDIR. These enumerated test witnesses are not native solver outcomes. No feasibility or optimality claim is made for unsupported profiles.
