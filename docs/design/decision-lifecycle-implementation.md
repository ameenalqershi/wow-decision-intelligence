# S11 — Decision lifecycle and approval policy (initial domain slice)

Scope #36 / TC-S11-A. DecisionStateMachine encodes the exhaustive lifecycle.md state graph (16 states, 27 allowed edges). Apply requires full tenant/model/revision identity, trusted actor and exact expected state/sequence, explicit permission and UTC time/causation/correlation. It emits the next immutable snapshot and one audit event, but does not persist either or claim atomicity. The trusted host resolves authorization, policy, current revision and persisted/replayed S10 evidence; never bind TransitionAuthority, persisted state or receipt directly from a client. E01/S12 service authorization must check every operation and the live current revision. Validation/compilation/admission/fenced worker guards remain host-owned S12 responsibilities.

Solved attaches exact same-scope S10 evidence, including rejected/unknown outcome for audit. Verified requires independent primal or complete proof; Proposed requires a verified feasible incumbent and Completed/Timeout, not Cancelled/Failed. Proposal digest binds tenant/model/revision, immutable evidence, payload hash, destination, creator, expiry and immutable policy semantics (ID, version, sensitivity, execution switches and ordinal approved targets). Approval binds proposal and approver/time/expiry; sensitive self-approval rejects. Approval and execution recheck current revision, evidence, policy and expiry. Default deployment must disable external execution and sensitive execution; changing the switches invalidates previous approvals. The positive execution test deliberately uses an explicitly enabled synthetic policy; this is not permission to enable production write-back. Executing creates a deterministic logical execution ID, not an external call. Executed/Failed from Executing require corresponding confirmed outcome and matching receipt digest; ambiguity leaves the current state unchanged. E04/I04 own external idempotency, outbox and reconciliation. Superseded requires a newer current revision; terminal states are not reopened.

Five local tests: exact transition table across all 256 pairs and actual rejection of 229 forbidden pairs; happy guarded path and wrong proposal/approval digest, policy/version changes, expiry and separation of duties; disabled policy; rejected/unknown/cancelled/foreign evidence; sequence, scope, permissions and supersession. Evidence is produced by the actual S10 capture component with synthetic fixtures. The remaining allowed edges still require individual positive tests; no persistence or real HTTP/E01/DB qualification from these component tests.

Remaining gates: authoritative E01 authorization service and current-revision/actor validation; PostgreSQL transaction with compare-and-swap sequence, append-only audit and rejection audit, revision/evidence references and execution ID uniqueness; actual concurrency, rollback, restore and HTTP authorization tests; qualified host integration with S12/E04. Keep Active and Draft. Do not treat an in-memory state-machine result as durable transition, approval or external authorization. No new public wire contract.
