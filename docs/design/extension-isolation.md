# E07 — Extension isolation (initial Linux profile)

Scope #81 / TC-E07-A / F04 B4. The trusted host obtains an authenticated, authorized frozen lease through E01/S12 and resolves an approved extension identity through EXT01. ExtensionAdmission checks exact tenant/model, extension ID/version/package digest, explicit requested capability set and budget against a live approval directory. Unknown capability, absent grant, changed package/version, mismatched tenant and excess budget reject. A manifest alone is not approval. Recheck after staging. No extension assembly loads into server or UI.

LinuxExtensionSandbox prepares a fixed Bubblewrap invocation for the S07 worker executor; no arbitrary command, mount, environment or network permission is accepted from a plugin or user. The deployment must provision a protected minimal immutable Linux rootfs containing /usr/share/dotnet/dotnet and empty /plugin, /input, /scratch, /tmp plus /proc and /dev mountpoints. Runtime rootfs, content-addressed bundle store, trusted Bubblewrap binary and private staging must be separate, immutable to untrusted principals. The rootfs itself must contain no host secrets and must be approved/pinned by deployment; it is not the host root. Package digest uses ordered ordinal relative UTF-8 paths with length framing and SHA-256 file hashes; bounded entry count and bytes, reject symlinks/special files/hard links using statx, exact source digest and bounded input. This digest is integrity, not signature/provenance; SEC02 and EXT01 must verify publisher and immutable installation. Do not treat this as an archive unpacker. The host protects paths from concurrent mutation. Linux kernel/user namespace, mount, PID, IPC, network and capability isolation are requested, environment cleared, private bounded tmpfs and no host writable mounts. Optional EphemeralScratch grants additional scratch; the fixed runtime temp mount is always ephemeral and memory-accounted, not a durable write permission. The host must use an actual S07 enforced cgroup scope; never execute the prepared program directly. Only release staging after confirmed scope cleanup; quarantine unresolved cleanup. Denied preparation does not begin the worker, and the caller must cancel/expire the unused local lease. S12 durable fence and independent verification remain mandatory.

No Windows extension sandbox is implemented: the S07 Job Object alone is not file/network confinement; unsupported OS rejects. This first slice has three local tests for exact grant/denial, absent sandbox, package and input tamper/revocation, symlink rejection and staging lifetime. The argument inspection fixture uses /usr/bin/true only as a nonexecuted placeholder, not as an isolation implementation or proof. Bubblewrap is absent on the shared development server; actual untrusted extension process, blocked filesystem/network, limits and expiry tests are still required on a disposable configured host. Do not activate this profile in production, claim complete tenant security, or close #81 from these tests. E06 owns deployment/rootfs custody, EXT01 plugin contract, E08/QA04 integration qualification. No public wire change.
