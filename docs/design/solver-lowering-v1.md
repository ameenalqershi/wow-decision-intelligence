# M08 · Exact affine lowering
The managed lowering layer consumes the admitted M07 normalized graph, the original frozen UDIR, an S01 capability manifest and optional frozen flat facts. No native library is loaded. It supports finite affine domains and hard rows, a single default-weight zero-tolerance objective, and explicit Int64 or Binary64ExactInput encodings. It rejects scenarios, soft rows, unsupported objective policies, nonlinear terms and unknown required semantics. The rational.linear capability token for continuous affine inputs is proposed here for S03/S06 coordination; integer.linear already exists. A manifest is not evidence of native qualification.

Columns retain every original variable, ordinal native index, exact bounds and original source span. Rows retain every original hard constraint, including duplicates and constant contradictions. Fixed non-variable facts are resolved from verified input digest or singleton numeric domain; unknown/missing facts and out-of-domain values fail. Affine expressions are expanded by bounded iterative traversal. No presolve elimination of rows or variables occurs. Each row and objective is multiplied by its positive common denominator, preserving relation and objective order; the original objective is reconstructed by dividing its full scaled value (including offset) by that scale. Boolean assignments map 0/1 to false/true. Original revision digest and source lineage remain available. Independent verification remains S04.

Int64 encoding accepts only integral variables and conservative magnitude/activity bounds (long.MaxValue/2). Binary64ExactInput rejects non-dyadic bounds and coefficients outside the conservative 53-bit integer profile. Exact input encoding does not imply exact floating point backend arithmetic or certificate. No approximation is authorized. Temporal variable bounds must already be in the admitted tick unit and within the declared horizon. Native ABI and solver-specific constraints are S02/S03 responsibilities after R07. The result cannot be interpreted as a solution or evidence.

TC-M08-A local tests: 11 cases including actual DML compilation, independent finite enumeration of 25 assignments, exact row and objective scaling, reconstruction, preservation of duplicates and contradictions, frozen fact digest, Boolean mapping, capability/domain and range rejection, nonlinearity and non-dyadic input rejection. No fabricated native result. Remaining review: coordinate the continuous feature token and native adapter-specific numerical profile; scheduling and other unsupported constructs must not be routed through this affine profile.
