## Benchmark protocol for X07–X09

Pin commit, config, compiler, solver/RID, dataset hash, host, core quota and random seeds. Generate disconnected, weakly coupled, dense, infeasible and objective-coupled families with edits at 1%, 10% and 100% of inputs. Track a separate real-world licensed corpus; [OR-Library job shop](https://people.brunel.ac.uk/~mastjjb/jeb/orlib/jobshopinfo.html) has useful public instances but check redistribution and distinguish makespan from weighted tardiness. Keep all revisions from one instance in the same train/test split. Randomize paired run order, separate cold and warmed runs, record idle machine/load, repeat per independent family and report distributions (p50/p95 and paired bootstrap intervals on families). Report wall latency including verification, first feasible latency, core-seconds, peak RSS, verification failures, valid incumbent, bound/gap and timeout frequency. Never compare only completed runs. Publish raw rows and compare equal resources, comparable quality and fixed deadlines. Predeclare success on a held-out workload before tuning. Any false certificate disqualifies the method, regardless of speed.
