# Revision-bound quota plan: observed results
Source/protocol b52a017; no changes to frozen NormalizedQuota. Development 960/960 valid (48 ten-revision histories); holdout 3840/3840 valid (192 histories). Each revision has two timed records. Total 1200 timing records use independent tiny exhaustive oracle, 3600 use companion DP at larger sizes. In-place membership and edge mutation preflight passed. 1680 cache hits and 720 misses across both splits. The measured cache path includes exact edge/quota equality, objective magnitude check, fresh objective sums, and cache rebuild on a miss. No cached objective or optimality claim.

At 4096 variables (holdout, 16 histories per family), paired median speedup on hits was 5.19x stable-unit, 1.99x stable-mixed, 2.11x revision-edits. All 16 histories in each family had positive hit-only speedup. Including all ten revisions and misses, stable-unit 3.36x (exploratory percentile bootstrap 95% CI 2.89–3.91); stable-mixed 1.72x (1.64–1.83); revision-edits 1.005x (0.90–1.05). Hence frequent structural edits can erase the benefit entirely. At 8 variables revision-edits full-history median speedup 0.89x (0.76–1.19). At 512 variables miss-only stable-mixed speedup 0.77x. All families, including slow cases, are preserved. Summary uses paired history-level sums for full-history, per-history median for hit/miss strata, 2000 deterministic bootstrap draws; exploratory CIs do not adjust for multiple comparisons or shared host noise. Model histories, not timing rows, are the resampling unit. One Linux host only; no end-to-end solver timing or independent native evaluation of these exact cache histories.
