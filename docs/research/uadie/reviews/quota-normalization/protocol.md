Hypothesis: eliminate equal-count orientations; subtract minimum counts; divide positive count increments by GCD; optionally complement choices to reduce target; sort marginal costs if all normalized increments are one; otherwise exact descending 0/1 DP. All arithmetic restricted to sum(abs(delta)) < Int64.MaxValue. Odd cycles and unreachable exact counts return null. No general inequality/weighted/multiple quota claim.
Proof: each bipartite component has exactly two complementary assignments. Equal counts permit independent cheaper choice. Remaining orientations have fixed low-count base and a positive integer increment w with signed cost difference d. Any selection is bijective with a feasible orientation choice up to equal-count optimal ties. GCD divisibility is necessary and quotient preserves equality. Complement maps target to total-target and negates each d. Unit increments require exactly t choices; exchange of a chosen larger cost with unchosen smaller cost cannot worsen the objective. Otherwise descending DP maintains exact minimal cost for each attainable count by induction, each increment used at most once. No infeasibility of omitted constraints follows from finite residual. Complexity graph O(n+e), unit path O(m log m), DP O(m*t) time O(t) extra memory; m is remaining components, t normalized complemented target.
