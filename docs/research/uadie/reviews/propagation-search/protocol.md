# G8 challenger: exact early cardinality propagation
Motivation: G7 spent too much on certificates, while general cardinality rows were checked late by the warm reference. Use a standard constraint propagation technique, not a novelty claim. At each search node, k selected and r unassigned bits in a row imply count interval [k,k+r]. Reject if k>upper or k+r<lower. If k=upper force all remaining row bits to zero; if k+r=lower force all remaining row bits to one. Repeat until no assignment changes; at most n new assignments. Every forced bit is necessary in every completion; contradictions exclude only infeasible completions. Branch on an unassigned bit; a signed unary Box floor lower-bounds every completion. Checked feasible old witness may prune equal/higher cost. Induction on remaining bits proves exactness, including infeasibility. Not a new mathematical technique. Worst case exponential; cost O(n*m) propagation per node, n<=12 only. Input admitted by common research pipeline. No new production claim.
