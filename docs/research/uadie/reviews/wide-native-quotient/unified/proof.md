# Dependency-aware exact composition and restricted flow proof
For admitted Boolean model let each source constraint be a hyperedge on its participating variables (pair edges, fixed variables, bounded unit cardinality rows); an empty admitted row is the tautology 0<=0<=0. Fresh DSU constructs connected components of this full constraint incidence graph; no dynamic deletion use of stale DSU. A partition is sound if every variable belongs to exactly one block and each original constraint lies entirely within a block. The independent replay verifier checks ownership, exact projection of every original edge/fix/row and current cost, and replays each local proof, rather than trusting the producer's connectivity. Empty rows kept in first block in source order. Given sound partition S_1..S_k, feasible set is Cartesian product F_1 x ... x F_k, objective=sum c_j x_j; any feasible global assignment costs at least sum local minima. If every local result has independently verified optimum, concatenation attains this bound, so global result is optimal. If any block cannot produce formal optimum the dispatcher discards the tentative composed result and uses a monolithic admitted path. No formal infeasibility certificate composed; native status remains native.
Private token identity is exact sorted global member list, local n, ordered pair/fix entries and row scopes/bounds, and objective vector. The token depends on the current full constraint partition: rebuilding components from all current edges ensures merging or splitting changes member identity, so old proof cannot be used. Unchanged exact local model has identical feasible set and costs: its previously verified optimum and proof remain valid, independent of other disjoint blocks. Objective-only edits: reuse transformation proof only on exact local shape match, bind current objective and independently recompute orientation costs (G16 theorem). Transport prior direct witness only if current exchange proof succeeds; otherwise solve direct anew and verify. Assignment transport fixes prior column potentials, sets new row potential to current matched cost minus column potential, verifies every current dual inequality and primal-dual equality; if not, solve anew. Flow transport optionally reuses old residual potentials and witness only on exact shape, checks current source feasibility, cost and every residual inequality; else fresh flow. No stale optimum from structural or hash equality alone. Cache is private single-owner during Solve, exported outcome deep copied by JSON serialization; no input mutation during snapshot. Exact result hits and successful current proof transport separately counted; rebuilt includes fresh solves even where structural proof alone reused, and monolithic invocation counter is not a precise graph-build count. No dynamic graph update or row-level partial transform claim.
Restricted flow: each source variable is exactly one unit-capacity arc from a left row to a right row, and appears in exactly those two rows. All left rows equality1, all right either equality1 with balanced sides, or lower0/upper1. No other source constraints. Independently check row partition, arc incidence and original source primal. Build network left node supply1, right-to-sink cap1 and cost0, sink demand number of left rows; source variables arc cap1 and signed unary cost. For exact balanced rights total flow implies each right saturated; for optional rights flow may be zero or one. Thus integral feasible flows and source assignments correspond bijectively; objective unchanged. Native OR-Tools MinCostFlow finds a candidate; Bellman-Ford on residual arcs derives potential p such that c(a,b)+p[a]-p[b]>=0 for every residual arc (forward if unused, reverse if used); verifier independently checks inequalities on each source arc and right-sink load. Difference of two feasible flows decomposes into residual cycles; reduced costs telescope around cycles, all nonnegative, so no feasible improvement exists. This is exact optimality proof in admitted scope. Negative residual cycle or invalid proof rejects; native infeasible/unsupported abstains, no independent Hall proof yet. No general capacitated network, transportation, arbitrary side constraints, weighted matrix or mixed domains claim.
Complexity DSU O((n+e+q) alpha(n)), partition projection O(n+e+q) aside from grouping/sorting; private exact identity scans O(local n+e+q); aggregate proof and source encoding still linear in full data plus local proof size. Direct sorting and assignment Hungarian as prior proofs. Flow native complexity not claimed; residual Bellman-Ford O(VE), verifier O(E+sum row scope sort costs) with Int128 arithmetic. Worst-case attempted decomposition adds overhead before safe fallback; cost heuristic affects performance not mathematical correctness.
Prior art: known decomposition in constraint optimization (https://www.cs.toronto.edu/~fbacchus/Papers/MB_CP2008.pdf), known assignment reduction to min-cost flow https://developers.google.com/optimization/flow/assignment_min_cost_flow, OR-Tools API https://or-tools.github.io/docs/dotnet/classGoogle_1_1OrTools_1_1Graph_1_1MinCostFlow.html ; Hungarian/dual, DSU, graph decomposition, exact cache, and residual optimality are established. The implemented combination and evidence lifecycle are engineering research, no original algorithm theorem beyond the restricted composition/reuse argument claimed. Independent code verifier and native references are not an external human review.
