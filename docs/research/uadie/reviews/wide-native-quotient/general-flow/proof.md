# General bounded single-commodity network
Given node supply b (outflow minus inflow), arc lower l, upper u, cost c, integer x. Set y=x-l, then 0<=y<=u-l, b'=b-net(l), objective sum c*y+sum c*l. This is a bijection with exact integer cost and conservation. Native mincost flow yields candidate. For each residual forward arc if x<u, require c+p[from]-p[to]>=0; reverse if x>l require its negative>=0. Any feasible difference decomposes into residual directed cycles; potentials telescope and each residual cost is nonnegative. Thus candidate is optimal. Independent verifier checks all bounds, conservation, objective and residual signs with Int128; does not trust native status. For any node subset S, sum b(S)=outflow-inflow<=sum u(out)-sum l(in). Strict violation is an independent infeasibility certificate. For native reported infeasibility, augment shifted network with super-source for positive supplies, super-sink for demands; BFS residual maxflow obtains reachable cut if demand cannot be satisfied; verifier independently checks original strict inequality. If cut unavailable, fail closed, do not publish formal infeasibility. Bounded BFS iterations and network work envelope; no proof of support for all sizes. Potential recovery O(VE), residual verification O(V+E), cut verification O(V+E); BFS maxflow worst-case O(VE^2), capped. Source model explicit graph, no arbitrary linear-matrix discovery, side constraints, multicommodity, rational or unbounded flow. Digest logged in study envelope, certificate not separately authenticated or persisted as a new replay format. Known lower-bound shift, residual optimality and maxflow-mincut; no original algorithm claim. OR-Tools documentation https://developers.google.com/optimization/flow/mincostflow .
