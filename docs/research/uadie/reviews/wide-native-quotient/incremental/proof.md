# G13 mathematical obligation and scope
Consider Boolean x, exactly-one pair graph E, fixed bits F, ordered rows L <= sum_{i in S} x_i <= U, distinct indices within each S, and signed unary integer objective. Every connected bipartite component has precisely two complementary assignments; an odd cycle is infeasible. Intersect orientations with all fixed assignments; empty intersection proves infeasibility. A surviving single orientation becomes constant. Free orientations y_j define x_i=b_i+(1-2b_i)y_j, with b_i in {0,1}; fixed x_i=b_i. Each source variable belongs to one component. This is a bijection between assignments satisfying E,F and assignments of the free y variables, including isolated vertices. Substitution gives row constant B=sum b_i and d_j=sum(1-2b_i) over the row's free indices. L-B <= sum d_j y_j <= U-B is equivalent to the original row. The interval [sum min(0,d_j),sum max(0,d_j)] contains every possible residual row value; disjointness proves contradiction, containment permits deleting that row. It is not in general a proof of feasibility. The objective is offset=sum c_i b_i and coefficients sum c_i(1-2b_i). Exact substitution preserves every original cost, so any proven optimum of the transformed model reconstructs an original optimum. Nonconclusive native status remains nonconclusive. Current primal feasibility is independently checked against original rows, not just transformed rows. Native solver's optimality status is distinct from an independently checked formal proof.
The private plan copies exact ordered edges, fixes, row bounds, scopes, n and immutable maps. No objective is stored. On exact full-content equality E,F,rows,n the prior plan represents the identical feasible set and mapping; recompute all offset/coefficient values from current costs. On mismatch rebuild from scratch. This is a sufficient reuse condition, not a necessary canonical equivalence condition: reordered rows/edges rebuild. A plan can cache structural infeasibility only when the exact infeasible structure matches. Invalid and pre-cancelled calls cannot publish a partial plan. Single-owner synchronous session; concurrent input mutation is unsupported; overlapping calls rejected. Plan is not bound to production tenant/revision ID; evidence SHA256 includes current full model, not an authorization check. No native solver state cached.
For n vertices, e pair rows, f fixed entries and q total row memberships, admission and snapshot/equality O(n+e+f+q) ignoring hash-table adversarial costs, graph O(n+e), transformation expected O(q+sum_j k_j log k_j) from coefficient dictionaries and sorted active keys; memory O(n+e+f+q) plus native model, objective/reconstruction O(n), exact native optimization can be exponential. Objective magnitude <= 2^50 using Int128 makes all source and transformed disjoint sums and signed differences representable in Int64 and exact integer binary64 range; native solver tolerances still apply. Independent HiGHS reference on moderate coefficients and exhaustive small models are empirical, not universal formal proof. G12 threshold unchanged and heuristic; route correctness independent of it.
