# Template reuse proof obligation
The G13 plan defines the exact reduced feasible set independent of the unary objective. The private CpModel template contains only its Boolean variable domains and transformed constraints. Upon matching the full shape the variable/row sets are unchanged. Clear both integer and floating objective proto fields, rebuild integer objective from the current source costs and mapping, then instantiate a fresh CpSolver. The resulting objective and feasible set equal a cold construction modulo irrelevant ordering; no previous search status or bound is reused. A structural miss or exception discards the template; the old valid structural plan can remain independently and rebuild the native template on next access. No-edge/few-fix bypass solves the original model exactly with native status unchanged. Feasibility of returned original bits is independently checked. This only qualifies a single-owner session without input mutation during a call. Tests exercise complete objective replacement, recovery and isolated concurrent sessions. It is a managed model-template cache, not persistent native search state or dynamic graph maintenance. Objective/reconstruction remain O(n), and native solve complexity is unchanged; cache can reduce repeated model construction but retains extra native-proto memory. No mathematical originality claim.
