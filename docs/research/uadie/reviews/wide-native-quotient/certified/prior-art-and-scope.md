# Prior art and supported scope
Mathematical presolve/substitution: Achterberg et al., https://doi.org/10.1287/ijoc.2018.0857 . Proof logging for MIP presolve: Oertel et al., Certifying MIP-Based Presolve Reductions for 0-1 Integer Linear Programs, https://jakobnordstrom.se/docs/publications/CertifyingMIP-BasedPresolveReductions_CPAIOR.pdf ; VeriPB pseudo-Boolean proofs. VIPR https://github.com/scipopt/vipr verifies integer programming results in its own proof format. G15's restricted equivalence/exchange checker is not compatible with these full proof formats and does not establish originality. Algorithm selection and portfolio concepts predate UADIE; G15 uses simple development-calibrated feature routing, not a new general learning theorem.
OR-Tools CP-SAT supports solution hints (https://github.com/google/or-tools/blob/stable/ortools/sat/docs/model.md); they are not a guarantee of persistent search state or even feasibility. G14 caches managed model template, G15 uses a fresh solver and optional hint. HiGHS public C API https://ergo-code.github.io/HiGHS/stable/interfaces/c_api/ and guide https://ergo-code.github.io/HiGHS/stable/guide/further/ support model cost/bound edits and basis operations; LP basis reuse does not imply persistent MIP search state. No native persistent state reoptimization executed this cycle.
Scope matrix: Boolean exactly-one pair/fixed/unit-cardinality signed unary objective conditionally supported with verified quotient or native original; disjoint signed unit reduced rows support independent exact optimum proof; overlapping/general signed reduced rows use native reduced solver with verified transform but native status only. General binary weighted rows, general integer, continuous LP/MILP and scheduling constraints outside admitted grammar unsupported by this transformation; native original qualified solver needed, no coercion. Crew scheduling set-partition MPS demonstrated admission but no industrial optimum within budget; mixed original MPS fallback demonstrated only. Dynamic edge deletion not supported; rebuild on change. Tenant isolation, external proof deserialization, active cancellation, OOM, Windows and production evidence transactions remain open.
