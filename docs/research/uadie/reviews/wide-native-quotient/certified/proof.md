# G15 independent transformation and restricted optimum certificate
Admitted model: Boolean x in {0,1}^n, exactly-one pair edges, fixed binary assignments, distinct-member cardinality rows L<=sum x_i<=U and signed integral unary objective; magnitude sum abs(c_i)<=2^50. The producer colors the pair graph and assigns complementary component orientations. The verifier independently constructs connected components via union-find on all source edges (fresh build, never dynamic deletion). Each edge requires same map and complementary base bits. Every free reduced index must correspond to exactly one connected source component and must occur; every fixed component must have a source fixed anchor consistent with its base bits. Since same-map equality and complementary base bits propagate on graph paths, the verifier proves each free orientation gives all and only assignments satisfying its pair/fix rows, and the source assignment uniquely determines its orientation. Fixed components are uniquely determined. An odd graph or inconsistent fixed component is not certified here; abstain to original native solver.
For each free i, x_i=b_i+(1-2b_i)y_map(i); fixed x_i=b_i. The checker recomputes every original row's constant and grouped signed coefficient (including cancellation), exact adjusted bounds and sorted sparse coefficient list, and offset and objective coefficients using Int128. No row omission is accepted. Full source SHA-256 is calculated by caller; matching digest alone is insufficient and the checker rejects forged rebinding with changed cost/constraint semantics. The certificate is a claim of exact equivalence, not a trusted proof of arbitrary native optimality. Current scope is an admitted in-process model; no untrusted JSON deserializer, signature, tenant authorization or cryptographic identity guarantee.
For direct solve, tautological rows are identified by exact independent min/max over the Boolean cube; remaining row supports must be mutually disjoint and all coefficients +/-1. Substitute z_i=y_i for +1, z_i=1-y_i for -1; count bounds shift by number of negative coefficients and intersect [0,|S|]. Cost becomes a constant plus sum d_i z_i where d_i=sign_i*c_i. Pick the cheapest k variables, k=clamp(number of negative d_i,lower,upper). This minimizes cost for a fixed k and the sum of the k smallest costs is nonincreasing through negative d_i then nondecreasing. The independent checker proves row feasibility, no selected coefficient greater than an unselected one (no improving exchange), no positive selected coefficient if removal is permitted, and no negative unselected coefficient if addition is permitted; these conditions imply global minimum for the cardinality row, including empty groups and ties. Disjoint supports and free-variable sign minimization imply global optimum of the reduced model; equivalence transports this optimum. Unsupported rows/overlap/empty interval abstain from direct route, native reduced solve retains its original status. Original primal is checked once for all benchmark arms. No independent general native bound verification claim.
Complexity: graph O(n+e), independent union-find O((n+e) alpha(n)); row transform and check O(q log q) conservative bound for grouped/sorted memberships, memory O(n+e+q); direct sorting O(sum k log k), independent exchange proof O(n+q), native complexity unchanged. Evidence encoding may dominate for large certificates. No G13-style plan reuse in new certified route yet.
Cost model: A+pS+(1-p)F<F iff A<p(F-S), with A attempt cost, S successful remaining cost, F fallback cost and p probability. This is expected-cost break-even under fixed conditional means, not a guaranteed time improvement. Frozen cheap policy uses source row disjointness or upper proxy (edge+fix count)/n; not a calibrated prediction of absolute solve time. Dev-selected threshold .125; no tuning holdout. Mis-selection changes cost only; no mathematical status relaxation.
