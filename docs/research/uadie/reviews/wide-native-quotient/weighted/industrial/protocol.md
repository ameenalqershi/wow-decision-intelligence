# Weighted external re-admission (nine previously acquired MIPLIB models)
All nine existing external models, no favorable selection. Strict textual integer binary MPS parser, explicit UP=1/BV, one objective, RHS/bound set, no ranges, offsets or duplicate coefficients, unknown grammar abstains. Independent native HiGHS getLp and name getters compare exact column and row identity/order, cost, domains, integrality, source coefficient tuples and bounds (one-sided finite Boolean envelope), sense and offset. Any mismatch stops, never silently changes semantics. Source original gzip SHA256, individual MIPLIB licenses not confirmed, no raw redistribution. Same prior corpus, not fresh industrial dataset.
