# Ownership and equivalent assurance
Private ExecutionContext copies all source arrays before admission and computes one current digest. The dispatcher accepts a digest only through a private call with that same owned snapshot, not an externally asserted admission token. Top-level whole-model local proof may use the same current digest; projected local models require their own digest. No semantic change to routing, proofs, reconstruction or verification. Typed export clones all int/long arrays in source, result, quotient rows/maps/costs, assignment shape/matching/dual and flow proof, including nested results; strings/scalars are immutable. The source exported by shared-context path is separately copied, because whole-model token can retain the private source. Thus mutation of exports cannot mutate owned cache through these arrays. No CLR immutable array contract or protection against concurrent mutation of caller input during copying; trusted internal code must not mutate arrays. Complete independent UnifiedVerifier still checks source admission, digest, all constraints, proof and composition before measured evidence encoding. Byte equality across three policy arms is empirical evidence, not proof of all future versions. Existing G19 Decide unchanged by default.
