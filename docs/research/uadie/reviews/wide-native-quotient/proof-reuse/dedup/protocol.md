Replay exactly the prior G16 disk corpus (180 full records). Compare full JSONL against content-addressed zero-objective structural model and certificate objects with per-revision objective, solution and reduced witness; exact serialized byte comparison on hash hit, append and Flush(true) each new object before references, Flush(true) every revision. Read back independently, reconstruct full original model/certificate/result, verify source digest, transformation, objective, primal, direct proof, and exact byte-equal canonical serialization against original record sequence. Dedup writer performs extra object syncs, no relaxation of per-record sync. Test missing object, altered key, changed objective and missing reference. This is not a DB transaction, crash/power-loss qualification, authenticated log, hostile deserializer, or proof of native optimality.
